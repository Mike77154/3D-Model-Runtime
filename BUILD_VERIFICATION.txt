model_runtime89 build verification
==================================

Environment used for this bundle:
- GCC host toolchain available in the build container
- strict language check: -std=c89 -pedantic-errors -Wall -Wextra -O2

Verified after the final provider pass:
1. Full static library builds successfully with all linked providers/vendor sources.
2. Own runtime/provider sources pass tools/policy_scan.sh: no malloc/calloc/realloc/free/float/double tokens.
3. Provider dispatch regression: XPS probing is extension-gated before its native probe, so unrelated binary formats such as Genesis3D .act are no longer claimed as XPS.
